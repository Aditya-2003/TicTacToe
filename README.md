# 🎮 Tic Tac Toe - Human vs Computer

A browser-based Tic Tac Toe game built using **HTML**, **CSS**, and **JavaScript**, where you can play against either another human or a computer with adjustable difficulty levels: Easy and Medium.

## 🚀 Features

- ✅ Play against a Human or Computer
- 🧠 Computer has two difficulty levels: Easy (random moves), Medium (some logic to block or win)
- 🔄 Restart game anytime
- 📱 Responsive and easy to use UI

## 🎯 How It Works

- Choose your opponent: Human or Computer.
- If you choose Computer, you'll be asked to select a difficulty level.
- Take turns placing `X` and `O` in the 3×3 grid.
- The game ends when someone wins or it's a draw.

## 💻 Tech Stack

- HTML
- CSS
- JavaScript (vanilla)

## 📂 How to Run

1. Open any Browser
2. Search `adityastictactoe.netlify.app` and Press Enter
